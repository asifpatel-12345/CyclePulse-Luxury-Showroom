# 🚴‍♂️ CyclePulse | Modern Luxury Showroom Platform

An ultra-modern, interactive, glassmorphic luxury cycle showroom web application. Built with vanilla HTML5, CSS3 (Custom Properties & Glassmorphism design system), and JavaScript.

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Build](https://img.shields.io/badge/Status-Active-brightgreen.svg)
![Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JS-orange)

---

## ✨ Features

- **🚲 10 Flagship Cycle Showcase:** Includes Mountain Bikes (MTB), Aerodynamic Road Bikes, E-Hyperbikes, and BMX models.
- **⚡ Dynamic Category Filtering:** Instant multi-category filter mechanics without page reloads.
- **🛒 Interactive Shopping Drawer:** Real-time cart calculation, order list management, and live item counters.
- **🔍 Quick Spec Preview Modal:** In-depth bike performance metrics popup.
- **🎨 Dark Cyber Glassmorphism UI:** Neon cyan accents, ambient lighting effects, and smooth CSS transitions.
- **📱 Fully Responsive Design:** Tailored layouts for Mobile, Tablet, and Desktop displays.

## 🛠️ Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/asifpatel-12345/CyclePulse-Luxury-Showroom.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd CyclePulse-Luxury-Showroom
   ```

3. **Launch Live Server:**
   - Open VS Code.
   - Click **Go Live** on `index.html` via VS Code Live Server extension.
